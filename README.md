# BabelStone IDS Database

The BabelStone IDS database is a plain text listing (encoded as UTF-8) of Ideographic Description Sequences (IDS) for all encoded CJK Unified Ideographs.

This resource was maintained by Andrew West (魏安) (1960–2025), a respected linguist known for his work on East Asian scripts and Unicode. The current version supports Unicode version 16.0 (September 2024), and includes 97,680 entries.

We mourn the passing of Andrew West in July 2025. His contributions to the study and digital representation of historical scripts have had a lasting impact on the global scholarly and developer communities. His legacy lives on through the tools, texts, and standards he helped shape.

## About this repository

This GitHub repository is an unofficial mirror of the IDS.TXT file [originally published on Andrew West’s BabelStone website](https://www.babelstone.co.uk/CJK/IDS.HTML).

It was created and maintained by Ryusei Yamaguchi, who made a copy of the original data and published it here to ensure that Andrew West’s valuable work remains accessible and preserved in a form that shows its history of changes.

The aim is to make this important resource easier to access, reference, and maintain over time—especially for developers and anyone interested in CJK ideographs.

The data in this repository is also used in the [Mojidata Web App](https://mojidata.ryusei.dev/about), a web application developed by Ryusei Yamaguchi that provides an integrated interface for searching and displaying information from multiple open Han character databases.
